## 一、名称归一

### N1. 3b 用 2–3 字母缩写当病名检索和匹配【严重，系统性，最先修】
- **现象**：LRPPRC 病名清单 `Leigh syndrome / LS / LSS`，10 条新试验 9 条靠缩写进来：小细胞肺癌 "LS-SCLC"（5）、HIV 抗体 "3BNC117-LS" 等（3）、"Lumbar Spinal Stenosis (LSS)"（1）。
- **根因**：Step 2 的同义词里有极短缩写；3b 把它们当作和全称同等的病名，既用于 CT.gov `query.cond` 检索，也用于 Condition / Keyword 的整词匹配。癌症排除只作用于基因路径。
- **修法**：
  1. 病名分两类：全称 / 长同义词（≥ 4 字符或多词）照旧；**短缩写（≤ 3 个字母数字字符）不单独检索、不单独作为相关依据**，只有当同一条 Condition / Keyword 里同时出现全称或长同义词时才算数。
  2. 病名路径也加上癌症 / 标志物语境排除（与基因路径共用 `genecontext.CANCER`）。
  3. 同一规则检查 3c、L3、3e 是否也用了短缩写检索（L3 已有"≥ 4 字符病名"限制，3c 待查）。
- **审批**：B（会排除原来被收入的试验）。
- **测试**：正向——"LS-SCLC"、"3BNC117-LS"、"Lumbar Spinal Stenosis (LSS)" 不再使 Leigh 综合征病人命中；反向——"Leigh Syndrome"、"Leigh syndrome (LS)" 仍命中；真有短名的病（如 "CF" 只与 "Cystic Fibrosis" 同现时）不受影响；癌症语境在病名路径被排除、罕见病自身名字里含 "cancer" 的情况单列测试。
- **评测病例影响**：任何病名有短缩写的评测病例都会受影响（只会减少误收），需在改后统一重跑 3b。

### N2. L3 文献检索覆盖不到文献常用叫法【优先，系统性】
- **现象**：THRA 检索式只有 MONDO / OMIM 名（"congenital nongoitrous hypothyroidism 6" 等），文献常用 "resistance to thyroid hormone alpha / RTHα"，0 篇。
- **修法**：L3 检索名单加入（a）"<基因> related disorder / syndrome / deficiency"、"<基因>-related"；（b）Orphanet 与 OMIM 的同义词（来自已下载的数据集，不在线临时抓取）；短缩写按 N1 规则处理。
- **审批**：A（只会增加候选文献，新条目经核查后多为有条件）。
- **测试**：THRA 的检索式含 "THRA-related" 与 Orphanet 名；短缩写不进检索式；FOXF1、PSMD12 检索式只增不减。
- **评测病例影响**：会影响没有 GeneReviews 专章的评测病例（它们的支持治疗只能靠 L3 / L4）。

### N3. 换说法的同一行动跨章节重复
- **现象**：SNRNP200 禁忌节 "UV-blocking sunglasses" 与支持治疗节 "UV-A and UV-B blocking sunglasses"。
- **根因**：同义合并只在同一小节内做。
- **修法**：账本层加跨章节查重：同一来源同一句（或同一药物键 / 同一策略键）在两节各出一条时，按章节优先规则只保留一节，另一节记为"已在某节"，交叉引用交给 Step 4。行动名的语义相同（无药物键的措施类）用规范化词形 + 同一引文判定；判不准的列为"可能重复"进审阅，不自动删。
- **审批**：A（不改状态，只合并）。
- **测试**：测试集 `SAME-SNRNP200-UV-SUNGLASSES` 改为计分；反向——同一句里两个不同措施（如"助听器、人工耳蜗"）不合并。

### N4. 多个诊断分支时同一药物键在同一节生成多条
- **现象**：SFTPC 两个诊断分支，甲泼尼龙（`drug:rxcui:6902`、同一篇 PMID 33179299）各生成一条。
- **修法**：3c（及 3a、3b 同类路径）按行动键合并，`applies_to` 和 `status_by_branch` 记两个分支，与 3a 的做法一致。
- **审批**：A。
- **测试**：两个分支、同一药、同一文献 → 一条行动、两个分支状态；反向——不同药物键不合并。

## 二、语义核查

### S1. 疗效方向核查看不到"病人是谁"
- **现象**：GEMIN5 辅酶 Q10，原文两例用后神经症状改善，报告写"没有证据表明有效"。
- **根因**：`offlabel.direction` 只把用药句和结局句给核查；病人身份（"compound heterozygosity at the GEMIN5 gene in both cases"）在摘要另一句，3 次判定一致"部分支持"。
- **修法**：核查时附上题目和标出病人身份的句子作为上下文引文；或拆成两个核查项（病人是否该病 / 用药后是否改善）。
- **审批**：B（会把"未报告"变成"报告了改善"）。
- **测试**：测试集 `CLAIM-GEMIN5-COQ10`（期望支持）；反向——病人身份句指向别的病时仍不支持。

### S2. "证据不足"档的措辞过强；核查论断病句
- **修法**：固定措辞改为中性，如 "The available reports are not enough to judge whether it works."；指标名自带方向词（"improvements"）时不再套 "improved"。
- **审批**：A。
- **测试**：措辞不含 "no evidence that it is effective"；"neurological improvements" 生成的论断不出现重复方向词。

### S3. 禁忌语境下例外从句极性反转
- **现象**：RRM2B 丙戊酸 "should be used only in exceptional circumstances" 被写成禁忌"取决于特殊情况"。
- **修法**：3a 条件抽取在禁忌 / 避免语境里，"only in / unless / except / other than" 引出的成分记为**豁免**（`exemption`），不作为触发条件；禁忌本身按原文的一般规则判（通常为适用），豁免另行列出。
- **审批**：B（有条件 → 适用）。
- **测试**：测试集 `CLAIM-RRM2B-VALPROATE-INVERTED`（期望不支持）与 `-CORRECT`（期望支持）；反向——支持治疗语境的 "only if X" 仍是触发条件；禁忌语境的 "if X" 仍是触发条件。

### S4. 不良反应报告被当成治疗先例
- **现象**：MPZ 伏立康唑（PMID 18837430：因其他适应证用药后神经病变加重），被列为老药新用、状态"适用"。
- **修法**：3c 抽取增加"用药目的"字段，必须是治疗本病或本病的表现；核查项加一条"该药是为治疗本病（或其表现）而用"；不良反应 / 药物诱发类报告（"exacerbated by"、"induced"、"toxicity"）转为禁忌候选交给 3a 审阅，而不是老药新用。
- **审批**：B（会移除条目）。
- **测试**：测试集 `CLAIM-MPZ-VORICONAZOLE-ADVERSE`（期望不支持）；反向——GEMIN5 辅酶 Q10、LRPPRC 艾地苯醌这类治疗性报告仍保留。

### S5. 动物模型 / 别的基因的证据被判成"已确立 / 适用"
- **现象**：SNRNP200 "避免强光"，依据是视紫红质突变的动物模型。
- **修法**：3a 抽取时识别证据类型限定（"in animal models"、"in mice"、"particularly those with pathogenic variants in <另一基因>"），命中时状态降为"有条件"，并注明依据类型；不升级为已确立。
- **审批**：A（适用 → 有条件）。
- **测试**：测试集 `CLAIM-SNRNP200-BRIGHT-LIGHT`；反向——"戒烟"（原文明确 "recommended for all"）仍适用。

### S6. L3 核查论断不带条件，有条件的建议被整条丢弃
- **现象**：FOXF1 "病情较轻的部分 ACDMPV 病人可考虑肺移植"，核查论断写成无条件的"推荐肺移植"，判部分支持后丢弃。
- **修法**：L3 抽取同时取出原文的适用人群限定，论断带上该限定；核查通过后以"有条件"写入。
- **审批**：A（新增条目为有条件）。
- **测试**：FOXF1 肺移植以有条件写入；反向——无限定的普通建议论断不变。

## 三、诊断规则

### D1. 原文点名的病种群压过 ClinVar 指向的更具体疾病【已批准】
- **现象**：B1-L2 描述第一句点名病种群，Step 2 按"临床文本明确点名优先"选了更宽的名字：LRPPRC 法裔加拿大型 → Leigh 综合征；MPZ CMT1B → CMT。随之引入亚型不符的试验（CMT4J 的 ELP-02）。
- **规则（2026-11-11 批准）**：原文点名的病种群在 MONDO 中**包含** ClinVar 指向的更具体疾病时，取更具体的；两者无上下位关系时仍以原文为准。
- **修法**：Step 2 选主诊断时，对"explicit"候选做 MONDO 祖先检查（用已下载的 MONDO 本体，不在线查）；理由里同时记下原文点名的名字和 ClinVar 记录，便于 Step 4 呈现。
- **测试**：正向——"Leigh syndrome" + ClinVar 指向 LSFC → LSFC；"Charcot-Marie-Tooth disease" + ClinVar 指向 CMT1B → CMT1B；反向——原文点名与 ClinVar 无上下位关系（例如两个平行的病）→ 仍取原文；原文点名比 ClinVar 更具体 → 取原文；ClinVar 无记录 → 取原文。
- **验收**：Step 2 验收全过；`acceptance_eval_cases.py --eval` 确认 4 个评测病例诊断不变；盲测 12 例缓存重跑，列出诊断变化（预期只有 LRPPRC、MPZ 变回更具体的病）。

### D2. 亚型限定的试验与老药新用未对照病人基因型
- **现象**：MPZ 病人进了 CMT4J 专用试验（已判写错）和要求 "duplication of the PMP22 gene" 的试验（NCT07140614，判为有条件）；LRPPRC 的西地那非先例来自 MT-ATP6 病人。
- **根因**：一部分来自 D1 的诊断变宽；另一部分是 3b 对"基因型类"入组标准（"genetic testing showing …"）没有对照病人已知的基因型，3c 对"先例病人的基因"没有和本病人对照。
- **修法**：3b 标准映射里，明确写出基因 / 变异要求的标准由代码对照病人基因型判定（病人基因型是已知事实）：要求的基因与病人不同 → 不满足；3c 先例记录先例病人的基因（原文提到时），与本病人不同则在结论中注明"先例来自 <基因> 病人"，状态降为有条件。
- **审批**：B（3b 会产生新的"不符合"）。
- **测试**：PMP22 重复要求 + MPZ 病人 → 不满足；反向——要求 "genetic confirmation of CMT"（不指定基因）→ 满足或未知，不判不满足；同基因不同变异 → 不因此判不满足。
